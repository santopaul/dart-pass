# Mobile Bus Pass

Simple mobile-first static site that reproduces the bus-pass layout from the provided images.

Run locally

1. Open `index.html` in a browser (no server required).

Notes
- The page uses `image2.png` from the workspace as the logo. If you'd prefer `image1.png`, rename or update the `img` `src` in `index.html`.
- Expiry is set to 4 hours from page load to match the "4 Hour" fare. You can change the expiry logic in `script.js`.
